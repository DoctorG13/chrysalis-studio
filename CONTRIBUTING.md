# Chrysalis Development Guide

## Philosophy

Help Donna run her business.

Every feature should reduce clicks,
reduce thinking,
or save time.

---

## Coding Rules

- Preserve architecture.
- Never redesign working code without reason.
- Complete one feature at a time.
- Prefer reusable components.
- Keep business logic outside UI components.
